# 安全设置、设备恢复与发布准备

## Goal

完成设置、安全恢复、设备生命周期、隐私控制、iOS 一致性和发布门禁，使前序 Android 功能具备可发布的产品边界。

## Requirements

- 补齐应用锁设置、PIN/恢复材料、换机、设备撤销、解绑与本地数据选择。
- 补齐通知隐私、后台遮罩、截图/录屏能力边界、导出和账户/共享内容删除区分。
- 对 iOS 的 Keychain、生物识别、原生 E2EE、文件和同步进行独立验收。
- 固化 AGPLv3 对应源码与第三方 notices、依赖升级/回滚、签名和商店发布门禁。
- 安全审计或未完成的审计必须成为显式发布条件。

## Acceptance Criteria

- [ ] 设置中的每个可点击入口都有真实功能或明确不可用状态。
- [ ] 恢复、换机、撤销、解绑和删除对两端数据的影响经过真机验证。
- [ ] Android/iOS、许可证、升级回滚和发布候选门禁全部有可审计证据。
- [ ] 任务归档时更新父任务完成度并触发最终集成复核。

## Dependency

- 在前四个产品里程碑稳定后完成最终收敛；部分 Android 设置可以提前独立规划。
