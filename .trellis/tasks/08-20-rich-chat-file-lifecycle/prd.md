# Chat 富消息与文件生命周期

## Goal

在真实身份和密文同步基础上补齐 Figma/PRD 的 Chat P0 消息类型、交互状态和加密文件生命周期。

## Requirements

- 覆盖文本、图片、文件、引用回复和系统事件。
- 覆盖发送中、已送达、失败、重试、撤回、长按/多选和阅后即焚规则。
- Save to Space 支持来源预览、类型表单、准确回跳和来源不可用状态。
- 附件使用流式加密与独立内容密钥，正文不通过 JS/native bridge 往返。
- 覆盖缓存、临时文件、失败清理、重启恢复和弱网性能。

## Acceptance Criteria

- [ ] 两台 Android 设备完成所有 P0 消息类型的发送、接收和失败恢复。
- [ ] 100 MB 级文件不通过 JS bridge 搬运正文，且临时材料可验证清理。
- [ ] Chat 与 Space 来源关系在撤回、删除和重启后保持正确。
- [ ] 任务归档时更新父任务完成度和声明边界。

## Dependency

- 在生产身份/配对和密文同步基础通过后启动。
