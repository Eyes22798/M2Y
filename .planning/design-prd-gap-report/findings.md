# 发现记录

## 设计稿已覆盖

- 启动、解锁、恢复码、配对/安全号码、欢迎引导。
- Chat 主界面、Shared Item 卡片、Item 讨论上下文。
- Space Home：需要你、接下来、置顶、最近更新、类型筛选。
- Agreement 详情、确认弹层、等待对方、删除确认。
- Activity、时间视图、统一搜索、设置、保存到 Space 面板。

## 主要缺口

- Chat 缺少图片、文件、引用、撤回、发送状态、失败重试、焚毁模式和长按/多选状态。
- Save to Space 未体现多选来源保留、五类结果页和准确回跳原始聊天。
- 收藏、待办、笔记、文件没有完整详情与状态流程；Agreement 也缺少请求修改、新版本与完成态。
- 首次使用缺少 M2Y-ID 生成、显示名/头像、三种配对方式、请求确认/拒绝/过期、换机和设备撤销。
- 设置仅有目录页，缺少每个子页和解绑数据处理选择。
- 缺少离线、同步、冲突、错误、空状态、加载、权限拒绝与恢复状态。
- “匿名配对”“永久移除且无法恢复”等文案与 PRD 的谨慎承诺/短暂撤销窗口存在冲突。
- 静态 SVG 无法证明 E2EE、零明文、推送隐私、幂等同步、性能与数据残留清除。
